# Project---WEB-CSS-JS-HTML-

### _Repositorio para hacer un projecto WEB de implementació CSS, JS i HTML sobre el juego SIGNALIS_

## Cómo utilizar esta página web?

### HTML:
1. Primero ir al index.html, que es lo que se mostrará primero y te guiará hacia home.html.
2. Dentro de la carpeta "pages" encontrarás: home.html, credits.html y about.html.
3. En el home estará la información principal (más arriba en la navegación verás las opciones de ver los creditos de los desarrolladores del juego y el about de porqué se creó esta página).
### Diseño y scripts
1. En assets se encuentran los css del index y de home _(home se ha compartido con el resto de páginas para abaratar costos)_.
2. Lo mismo sucede con los javascripts dentro de la carpeta js.
3. Font y img son contenedores de fuentes de texto e imagenes, respectivamente.
