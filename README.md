# Project---WEB-CSS-JS-HTML-
Repositorio para hacer un projecto WEB de implementació CSS, JS i HTML.
==========================
Cómo utilizar esta página web?

Primero está el index.html, que es lo que se mostrará primero y nos guiará hacia home.html, donde estará la información principal. Luego habrá más arriba en la navegación las opciones de ver los creditos de los desarrolladores del juego y el about de porqué se creó esta página.

En assets se encuentran los css del index y el de home, que se a compartido con el resto de páginas.
Lo mismo sucede con los javascripts dentro de la carpeta js.
Font y img son contenedores de fuentes de texto e imagenes respectivamente.
